# The Mission Board
The mission board is a robotics control board with space for up to 8 motors and 4 servos featuring both ESP32 and RP2040 processors at its core. It also has a display to achieve easier debugging and customization. Sensors include a gyro, accelerometer, and magnetometer.

# Full Feature List

- Gyro, Accelerometer, Magnetometer
- Up to 4 servos
- Up to 8 motors
- Display connector
- 2 USB for programming RP2040 and ESP32 (no power functionality)
- 1 Barrel Jack for power
- Debug Lights + 5 Customizable Switches

# Case

The case uses a bottom and top part; the bottom part holds the pcb while the top part holds the display. The top part is removable and uses 2 4M screws to attach, and the bottom part needs 3 6M screws to attach to the PCB.
